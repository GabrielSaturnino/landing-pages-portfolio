A pousada existe?

Não. Serra é uma marca fictícia e as cabanas são ilustrações autorais. Esta página demonstra a experiência digital de uma hospedagem.

A simulação confirma disponibilidade?

Não. O simulador calcula noites e tarifas ilustrativas. Não consulta calendário, não cobra e não realiza reservas.

Como os valores são calculados?

Aurora: R$ 390/noite para até 2 pessoas; Neblina: R$ 520/noite para até 4; Horizonte: R$ 590/noite para até 2. Na seleção automática, grupos de 3 ou 4 pessoas usam a Neblina.

Posso enviar meus dados para reservar?

Esta demonstração não coleta dados de contato. Em um projeto real, o fluxo poderia ser conectado a um motor de reservas ou atendimento.
